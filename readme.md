# Data Analysis & Analytics Portfolio

Welcome to my central data analysis repository! This monorepo features end-to-end data pipelines, exploratory data analysis (EDA), and action-driven business insights across various datasets.

---

## 🛠️ Tech Stack & Tools

- **Languages:** Python (Pandas, NumPy, PySpark)
- **Visualization:** Matplotlib, Seaborn
- **Environments:** Jupyter Notebooks, VS Code, Databricks
- **Database / Tools:** SQL, Git/GitHub, FastAPI
